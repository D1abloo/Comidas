# Design Skills

Before UI or UX work, preserve the existing BocadO editorial visual language
and route broad production frontend changes through `frontend-design`.

- Review the current interface before editing.
- Present the A/B/C/D/E plan before broad visual changes.
- Prefer accessible, responsive improvements that preserve routes, data shapes,
  public APIs, copy, and brand identity.
- Treat navigation rewrites, brand replacement, new dependencies, public API
  changes, and data-flow changes as risky.
- Validate keyboard/focus behavior, 320-1440 px layouts, reduced motion,
  touch targets, loading/error states, build output, and runtime behavior.
- Prefer existing CSS variables, components, SVG primitives, and dependencies.
